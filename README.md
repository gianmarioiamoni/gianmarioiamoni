# 🧩 About Me

I'm an **AI Engineer and Full-Stack Developer** focused on designing and building reliable, production-oriented AI systems and modern web applications.

My work combines Python-based AI engineering with full-stack development using TypeScript, React, Next.js, and modern database architectures.

I focus on turning LLM capabilities into structured application workflows, with particular attention to:

- **AI Engineering:** LLM integration, RAG pipelines, semantic retrieval, and multi-agent orchestration.
- **System Architecture:** LangGraph workflows, modular design, state management, and separation of concerns.
- **AI Reliability:** Structured outputs, deterministic evaluation, validation, error handling, and automated testing.
- **Production Readiness:** Observability, token budget governance, cost control, and maintainable deployment architectures.
- **Full-Stack Development:** Scalable APIs, multi-tenant SaaS applications, authentication, and database security.

With a background spanning software engineering, telecommunications, and enterprise technology environments, I bring a systems-oriented mindset to the design of digital products.

I collaborate remotely with Italian and international teams.

# 🔥 Selected Projects

A selection of AI engineering and full-stack projects demonstrating my approach to architecture, intelligent workflows, and reliable software systems.

### 1. AI Interview Simulator

An AI-powered platform for practicing technical and behavioral interviews, with structured assessment and actionable feedback.

- Adaptive interview workflows tailored to the candidate's role, seniority, and difficulty level.
- Competency-based evaluation with structured scoring, strengths, improvement areas, and model answers.
- AI-assisted interview planning, follow-up questions, and difficulty adaptation.
- Structured reporting and feedback to support interview preparation.

**Stack:** Python, LLM APIs, AI workflow orchestration, automated testing.

🔗 [View repository](https://github.com/gianmarioiamoni/ai-interview-simulator) · [Portfolio](https://gianmario-portfolio.onrender.com/#work)

### 2. Enterprise AI Decision Engine

A structured decision-support system that combines knowledge retrieval, historical context, multi-stage analysis, and confidence modeling.

- Multi-stage LangGraph orchestration.
- RAG with separation of authoritative knowledge and historical precedents.
- Independent analysis and planning stages.
- Traceable decisions and structured reporting.

**Stack:** Python, LangGraph, LangChain, OpenAI, RAG.

🔗 [View repository](https://github.com/gianmarioiamoni/ai-decision-agent)

### 3. Tech Explanation Service

An AI-powered documentation assistant that generates structured technical explanations using Conditional RAG and real-time streaming.

- Dynamically selects documentation-based retrieval or general LLM knowledge.
- Streams generated answers in real time.
- Supports conversation history and document exports.
- Includes automated testing, usage tracking, and error handling.

**Stack:** Python, LangChain LCEL, OpenAI, ChromaDB, Gradio, SQLite, pytest.

🔗 [View repository](https://github.com/gianmarioiamoni/tech-explanation-service-langchain)

### 4. AI Knowledge Hub

A multi-tenant SaaS platform that transforms company documentation into an AI-powered knowledge assistant.

- Document ingestion, vectorization, and semantic retrieval.
- Context-aware question answering using RAG.
- Multi-tenant data architecture and database-level access control.
- Subscription-oriented SaaS architecture.

**Stack:** Next.js, TypeScript, React, Supabase, PostgreSQL, pgvector, LangChain, OpenAI, Stripe.

🔗 [View repository](https://github.com/gianmarioiamoni/ai-knowledge-hub)
